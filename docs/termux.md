# تشغيل SINDAR على جوال Android (بدون كمبيوتر)

> الوقت المتوقع: 5–10 دقائق · التكلفة: 0 ريال · تحتاج: جوال Android 7+ واتصال إنترنت

## 1) ثبّت Termux (مرة واحدة)

Termux برنامج مجاني يحوّل جوالك إلى "كمبيوتر صغير" بداخله — فيه يعمل عقل SINDAR.

- حمّله من **F-Droid**: <https://f-droid.org/packages/com.termux/>
  (أو من GitHub: <https://github.com/termux/termux-app/releases>)
- ⚠️ **لا تستخدم نسخة Google Play** — قديمة ومعطّلة.
- اختياري لكن مفيد: **Termux:API** من F-Droid <https://f-droid.org/packages/com.termux.api/> (يسمح لـ SINDAR بإرسال إشعارات، قراءة الحافظة، الكاميرا…).

## 2) ثبّت SINDAR (أمر واحد)

افتح Termux، والصق هذا السطر ثم اضغط Enter:

```bash
curl -fsSL https://raw.githubusercontent.com/djoeekoe-netizen/SINDAR/arena/ed5f3c48-sindar/scripts/install.sh | bash
```

> للّصق في Termux: اضغط مطوّلاً على الشاشة ← **Paste**.

السكربت يقوم بما يلي تلقائياً: **تحديث Termux كاملاً** (مهم — يمنع تعارض المكتبات) ← تثبيت Node.js ← تنزيل SINDAR ← تشغيل فحص الجاهزية `sindar doctor`.

> ⚠️ لا تثبّت حزماً منفردة قبل ذلك (مثل `pkg install curl`) — `curl` موجود أصلاً في Termux، وتثبيت حزمة واحدة فوق نظام قديم يسبب خطأ `CANNOT LINK EXECUTABLE`. أبقِ الشاشة مفتوحة والشاحن موصولاً أثناء التثبيت.

في النهاية سترى تقريراً مثل:

```
فحص SINDAR — الإصدار 0.1.0 (a1b2c3d)

✔ Node.js v22.x
ℹ المنصة: Android (Termux 0.118) · arm64 · الصدَفة: bash
✔ تم إنشاء مجلد SINDAR لأول مرة: /data/data/com.termux/files/home/.sindar
✔ الإعدادات: config.yaml · النموذج الافتراضي: mock:echo
✔ قاعدة البيانات: node:sqlite · SQLite 3.x · بحث نصي FTS5 · المخطط v1
...
النتيجة: جاهز مع 2 تنبيه
```

**أرسل لي هذا التقرير كاملاً** (انسخه من Termux) — هو شرط قبول المرحلة M0.

## 3) إعدادات مهمة للجوال

| ماذا | لماذا | كيف |
|---|---|---|
| **عطّل تحسين البطارية لـ Termux** | حتى لا يغلق Android العقل في الخلفية | إعدادات Android ← التطبيقات ← Termux ← البطارية ← **غير مقيّد / Unrestricted** |
| **فعّل التخزين المشترك** | ليستطيع SINDAR قراءة ملفاتك (الصور، التنزيلات…) | في Termux: `termux-setup-storage` ثم اسمح بالإذن |
| **أبقِ Termux مفتوحاً أو في الخلفية** | الإشعار الدائم لـ Termux طبيعي — لا تزله | — |
| **Huawei / Honor / Xiaomi: اسمح لـ Termux بالعمل في الخلفية** | هذه الأجهزة تجمّد التطبيقات في الخلفية وتقطع عنها الإنترنت — فلا يرد SINDAR حتى تفتح Termux، أو تظهر «تعذّر الاتصال» | **الأسهل:** اكتب في Termux `sindar background` — يتعرّف على نوع جوالك ويفتح لك كل شاشة إعدادات بدورها (اضبطها، ارجع إلى Termux، اضغط Enter). يدوياً: الإعدادات ← التطبيقات ← Termux ← البطارية ← **تشغيل التطبيق** ← أوقف «إدارة تلقائية» وفعّل الثلاثة (تشغيل تلقائي، تشغيل ثانوي، تشغيل في الخلفية)؛ ثم الإعدادات ← التطبيقات ← Termux ← **استخدام البيانات** ← اسمح بالبيانات في الخلفية؛ وفي Huawei أيضاً: البطارية ← إعدادات إضافية ← «البقاء متصلاً أثناء السكون». افعل الشيء نفسه لتطبيق **Termux:API**، وثبّت Termux بالقفل 🔒 في شاشة التطبيقات الأخيرة |

## 4) أوامر ستحتاجها

| الأمر | الوظيفة |
|---|---|
| `sindar doctor` | فحص الجاهزية |
| `sindar doctor --lang en` | نفس الفحص بالإنجليزية (أوضح في الطرفية) |
| `sindar update` | التحديث لآخر نسخة |
| `sindar background` | (أندرويد) إعداد الجوال ليبقى العقل حيّاً في الخلفية — خطوة بخطوة |
| `sindar memory` / `sindar skills` / `sindar sessions search <كلمة>` | الذاكرة والمهارات والبحث (الفقرة 8) |
| `sindar --help` | كل الأوامر |

> **ملاحظة عن النص العربي في Termux**: الطرفية تعرض العربية بشكل مقبول لكن ليس مثالياً (قد تظهر الحروف مفككة). الواجهة الجميلة بالعربية من المتصفح موجودة الآن (الفقرة 7)، وتطبيق مستقل يأتي في **M5**. للطرفية يمكنك استخدام `--lang en`.

## 5) حل المشاكل

| المشكلة | الحل |
|---|---|
| `CANNOT LINK EXECUTABLE "curl": cannot locate symbol …` | Termux قديم وجرى تحديث حزمة واحدة فقط. شغّل: `apt update && apt full-upgrade -y -o Dpkg::Options::=--force-confnew` ثم أعد أمر التثبيت |
| `sindar: command not found` بعد التثبيت | أغلق Termux تماماً وافتحه من جديد |
| `npm ERR! 404` أو فشل التنزيل | المستودع خاص أو لم تُبنَ النسخة بعد — انتظر دقائق أو أخبرني |
| `Unable to locate package nodejs-lts` | شغّل `pkg update` ثم أعد المحاولة |
| التثبيت بطيء جداً | طبيعي أول مرة (تنزيل Node.js ~30MB)؛ استخدم Wi-Fi |
| Termux يُغلق تلقائياً بعد دقائق | عطّل تحسين البطارية (الخطوة 3) أو شغّل `sindar background` |
| الرد لا يصل في الواجهة إلا عندما أفتح Termux | أندرويد جمّد Termux في الخلفية. شغّل `sindar background` مرة واحدة واتبع الخطوات، ثم `sindar gateway restart`. الواجهة نفسها ستنبّهك بشريط «العقل لا يرد منذ نصف دقيقة» عندما يحدث ذلك |
| ضغطت Enter في `sindar background` ولم تظهر أي شاشة | في خطوة «تحسين البطارية» هذا طبيعي غالباً: نافذة أندرويد لا تظهر إذا كان Termux مستثنى أصلاً. اكتب **r** لفتح شاشة بديلة (القائمة الكاملة ← كل التطبيقات ← Termux ← السماح) أو اضغط Enter للمتابعة. في أي خطوة أخرى: **r** يجرّب شاشة بديلة، وإن انتهت البدائل يطبع لك المسار اليدوي |

## 6) المحادثة الحقيقية (M1) — مفتاح مجاني + `sindar onboard`

### أ) احصل على مفتاح Groq المجاني (دقيقتان)

1. افتح في المتصفح: <https://console.groq.com/keys>
2. سجّل الدخول بحساب Google (مجاني، بدون بطاقة).
3. اضغط **Create API Key** ← أي اسم ← **Submit**.
4. اضغط **Copy** لنسخ المفتاح (يبدأ بـ `gsk_…`). لن يظهر مرة أخرى — إن ضاع أنشئ غيره.

> بديل مجاني: Gemini من <https://aistudio.google.com/apikey> (زر **Create API key**).

### ب) أعدّ SINDAR مرة واحدة

في Termux:

```bash
sindar onboard
```

- اختر اللغة ← اختر **Groq** (الخيار 1) ← **الصق المفتاح** (اضغط مطوّلاً ← Paste؛ لن يظهر وأنت تلصقه، هذا طبيعي) ← Enter.
  بعد Enter يكتب لك «تم استلام مفتاح: gsk_…xxxx (56 حرفاً)» — إن كان الطول غير 56 أو ظهر تحذير، اكتب `y` وأعد اللصق (المرة الثانية يظهر المفتاح وأنت تلصقه).
  نصيحة: لا تكتب أمراً ثم تلصق في نفس السطر؛ اجعل كل خطوة إمّا كتابة أو لصقاً.
- سيختبر المفتاح، ثم يعرض قائمة نماذج — اضغط Enter للافتراضي (الأفضل المتاح، مثل `openai/gpt-oss-120b`).
  يحفظ تلقائياً نماذج احتياطية من نفس المزود تُستخدم عند الازدحام.
- وضع الموافقة: اختر **1 (اسأل دائماً)** في البداية.

### ج) تحدّث معه

```bash
sindar chat
```

جرّب مثلاً:

- «ما هي عاصمة اليابان؟»
- «أنشئ ملف NOTES.md في مساحة العمل فيه قائمة مشترياتي: حليب، خبز، تمر»
- «اقرأ ملفات هذا المجلد ولخّصها»
- «كم مساحة التخزين المتبقية؟» (ينفّذ `df -h` بعد موافقتك)

> **أوامر Termux:API (مثل `termux-battery-status`) قد تتجمّد** على بعض الأجهزة (خاصة Huawei/Xiaomi) إذا كان تطبيق Termux:API مقيّداً في البطارية — SINDAR يوقفها تلقائياً بعد 120 ثانية. الحل: إعدادات Android ← التطبيقات ← **Termux:API** ← البطارية ← غير مقيّد، وافتح تطبيق Termux:API مرة واحدة. دعم الجوال الكامل يأتي في M6.

**لإيقاف ردّ أو أمر جارٍ**: اكتب `/stop` ثم Enter (أو **زر خفض الصوت + c** — يعمل كـ Ctrl+C في Termux). للخروج من المحادثة: `/exit`.

عندما يريد تنفيذ أمر في الطرفية (أو الكتابة خارج مجلدك الحالي ومساحة العمل) سيسألك: اكتب `y` للموافقة، `n` للرفض، `a` للموافقة الدائمة في هذه الجلسة. الكتابة داخل المجلد الذي بدأت فيه المحادثة وداخل `~/.sindar/workspace` لا تحتاج موافقة.

> **حدود الطبقة المجانية:** Groq يسمح بنحو 8000 رمز في الدقيقة لكل نموذج. عند الازدحام سترى `⏳ انتظار…` ثم يكمل وحده أو يتحوّل إلى النموذج الاحتياطي. لإضافة احتياطي يدوياً: `sindar model --fallbacks groq:openai/gpt-oss-20b`. للمهام الطويلة يفيد مفتاح Gemini المجاني (حدود أوسع): `sindar onboard --provider gemini`.
>
> النماذج «المفكّرة» (gpt-oss, qwen3) تفكّر قبل الرد؛ يظهر `💭 يفكّر…` فقط. لعرض التفكير كاملاً: `sindar chat --show-reasoning`.

| أمر داخل المحادثة | الوظيفة |
|---|---|
| `/new` | محادثة جديدة |
| `/model groq:llama-3.1-8b-instant` | تبديل النموذج |
| `/usage` | كم رمزاً استهلكت |
| `/undo` · `/retry` | تراجع · إعادة إرسال |
| `/stop` | إيقاف الردّ أو الأمر الجاري |
| `/exit` | خروج (أو زر خفض الصوت + c) |

للعودة إلى آخر محادثة بعد إغلاق Termux: `sindar chat -c`

**اختبار القبول لمرحلة M1 (✔ نجح على الجوال 2026-10-14):** في مجلد فيه ملفات (`mkdir -p ~/test && cd ~/test && echo "ملاحظات" > a.txt && sindar chat`) اكتب: «اقرأ ملفات هذا المجلد ولخّصها ثم أنشئ ملف NOTES.md» ← يقرأ بالأدوات وينشئ `~/test/NOTES.md` ويلخّص بالعربية.

## 7) الواجهة من المتصفح (M2) — بدل الطرفية

العقل (الـ Gateway) يعمل داخل Termux، والواجهة تفتحها من متصفح الجوال وتضيفها للشاشة الرئيسية فتصبح مثل أي تطبيق.

### أ) حدّث ثم شغّل العقل

```bash
sindar update
sindar gateway start
```

يطبع لك رابطاً مثل `http://127.0.0.1:18789/?token=…` (الرمز الطويل هو مفتاح الدخول — خاص بجهازك).

### ب) افتح الواجهة

- الأسهل: اكتب `sindar dashboard` ← يفتح المتصفح على الرابط مباشرة (قد يسألك Android عن المتصفح؛ اختر Chrome).
- أو: اضغط مطوّلاً على الرابط داخل Termux ← **Open link**.
- أو: اكتب `sindar dashboard --qr` وامسح الرمز بجوال آخر على نفس الشبكة (يحتاج `sindar gateway restart --host 0.0.0.0`).

أول مرة فقط يحفظ المتصفح الرمز، وبعدها يكفي فتح الصفحة.

### ج) أضفها للشاشة الرئيسية

في Chrome: قائمة ⋮ ← **إضافة إلى الشاشة الرئيسية** (أو «تثبيت التطبيق») ← سيظهر لك أيقونة SINDAR مثل أي تطبيق. تفتح بملء الشاشة وبدون شريط عنوان.

### د) أوامر العقل

| الأمر | الوظيفة |
|---|---|
| `sindar gateway start` | تشغيل في الخلفية (يأخذ wake-lock حتى لا ينام الجوال) |
| `sindar gateway status` | هل يعمل؟ + الرابط |
| `sindar gateway stop` / `restart` | إيقاف / إعادة تشغيل |
| `sindar gateway logs` | آخر السجلّات عند وجود مشكلة |
| `sindar gateway token --rotate` | رمز دخول جديد (القديم يتوقف) |
| `sindar dashboard` | فتح الواجهة في المتصفح |

### هـ) الواجهة تقول «تعذّر الاتصال» أو `fetch failed`؟

العقل يعمل لكنه لا يصل إلى الإنترنت. جرّب بالترتيب:

1. افتح Termux لحظة (يعود الإنترنت للتطبيق) ثم ارجع للواجهة وأرسل من جديد.
2. إن نجح ذلك فجوالك يقطع الإنترنت عن Termux في الخلفية — طبّق إعدادات Huawei/Xiaomi في الفقرة 3 مرة واحدة.
3. أطفئ الـ VPN مؤقتاً إن كان لديك، أو تأكد أنه يشمل Termux.
4. `sindar gateway logs` يعرض تفاصيل الخطأ.

### و) ماذا لو انقطع الاتصال بالعقل نفسه؟

الواجهة تعرض شريطاً أصفر «انقطع الاتصال بالعقل» وتعيد المحاولة تلقائياً. السبب غالباً أن Android أغلق Termux:

1. افتح Termux واكتب `sindar gateway status`. إن كان متوقفاً: `sindar gateway start`.
2. تأكد أن تحسين البطارية معطَّل لـ Termux (الخطوة 3) ولا تُزل إشعار Termux الدائم.
3. (اختياري) ثبّت تطبيق **Termux:Boot** من F-Droid، ثم أنشئ ملفاً يشغّل العقل عند إقلاع الجوال:
   ```bash
   mkdir -p ~/.termux/boot && printf '#!/data/data/com.termux/files/usr/bin/sh\ntermux-wake-lock\nsindar gateway start\n' > ~/.termux/boot/sindar.sh && chmod +x ~/.termux/boot/sindar.sh
   ```

### ز) حدّثتَ SINDAR لكن الواجهة ما زالت قديمة؟

التطبيق المثبّت على الشاشة الرئيسية قد يبقى حيّاً في الخلفية أياماً، فيستمر بتشغيل النسخة القديمة من الواجهة. منذ هذه النسخة تكتشف الواجهة أن العقل صار أحدث منها وتعيد تحميل نفسها (أو تعرض شريطاً «وصلت نسخة أحدث — اضغط للتحديث»). إن لم يحدث ذلك: أغلق تطبيق SINDAR نهائياً (من شاشة التطبيقات الأخيرة، اسحبه للخارج) ثم افتحه من جديد.

**اختبار القبول لمرحلة M2 (✔ نجح على الجوال 2026-10-14):** `sindar gateway start` ← تفتح الواجهة وتضيفها للشاشة الرئيسية ← ترسل «أنشئ ملف أفكار.md فيه ثلاث أفكار لمشروع صغير» ← ترى بطاقة الأداة والردّ ← تغلق Termux (من الزر Home لا من «Exit») وتعود للواجهة فتجدها تعمل.

## 8) الذاكرة والمهارات والبحث (M3)

بعد `sindar update` ثم `sindar gateway restart` ستجد في القائمة الجانبية (☰) ثلاثة أشياء جديدة:

| ماذا | أين | ماذا يفعل |
|---|---|---|
| 🔎 **خانة البحث** | أعلى قائمة المحادثات | اكتب كلمة (عربي أو إنجليزي) فيعرض المحادثات القديمة التي ذُكرت فيها، واضغط لفتحها |
| 🧠 **الذاكرة** | زر أسفل القائمة | ما يتذكّره SINDAR عنك وعن أعمالك بين المحادثات (ملفان: «عنّي» و«الذاكرة») — يكتب فيهما بنفسه ويمكنك التعديل |
| 📘 **المهارات** | زر أسفل القائمة | طرق عمل محفوظة يستخدمها في المهام المتكررة؛ تأتي 4 مهارات جاهزة، وينشئ غيرها بعد المهام الطويلة، وتثبّت مهارات الآخرين من GitHub |

**جرّب هذا (هو اختبار القبول):**
1. قل له: «أفضّل الردود المختصرة، وأعمل على مشروع اسمه X» → يجب أن ترى بطاقة أداة `memory` → افتح 🧠 الذاكرة وستجد السطر.
2. ابدأ محادثة جديدة واسأله: «على ماذا أعمل؟» → يجيب من الذاكرة دون أن تعيد.
3. اسأله عن شيء ناقشتموه في محادثة قديمة («ماذا كتبنا في ملف الأفكار أمس؟») → يستخدم `session_search` ويجيب.
4. أعطه مهمة من عدة خطوات (مثلاً: «أنشئ مجلد تقارير وفيه ملف اليوم واكتب ملخصاً ثم اعرض محتوياته») → في نهايتها يعرض عليك حفظها كمهارة؛ وافق، وستظهر في 📘 المهارات. في المرة القادمة يقرأ المهارة وينجز أسرع.

**من الطرفية:**

```bash
sindar memory                      # عرض الذاكرة مع رقم كل سطر
sindar memory add "أفضّل الردود المختصرة" --user
sindar sessions search تقرير       # بحث في كل المحادثات
sindar skills                      # قائمة المهارات
sindar skills show git-workflow
sindar skills install github:anthropics/skills/skills/pdf   # مثال حقيقي
sindar skills remove pdf
sindar config set skills.autoCreate auto   # ليحفظ المهارات بنفسه بدل أن يسألك (أو off)
```

**نتيجة الاختبار على الجوال (✔ 2026-10-14):** بطاقة `memory` ظهرت وحُفظ التفضيل، و«على ايش كنا نشتغل» في محادثة جديدة أجاب «كنا نعمل على إنشاء ملف أفكار.md…»، و`sindar skills` وصفحة 📘 تعرضان المهارات الأربع. ملاحظة: إن ذكرت أكثر من حقيقة في جملة واحدة وحفظ النموذج واحدة فقط، أضف الباقي بنفسك من 🧠 أو بـ `sindar memory add "…" --user`.

> الأمان: المهارات المثبّتة تُفحص قبل الكتابة (أوامر تنزيل-وتشغيل، حذف شامل، لمس مفاتيح SSH أو أسرار SINDAR، SMS/اتصالات، تعليمات مخفية) وتُرفض إلا إذا أكّدت بـ `--yes`. السكربتات داخل المهارات لا تعمل تلقائياً أبداً — SINDAR يشغّلها عبر أداة الطرفية وبموافقتك كأي أمر آخر.

## 9) ماذا بعد؟

**M4**: قناة Telegram — تكلّم SINDAR من تطبيق تيليجرام (على نفس الجوال أو من أي مكان) مع اقتران آمن بكود.
